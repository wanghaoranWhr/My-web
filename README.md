## 🎯 一、 项目背景与痛点

在农业防灾减灾领域，以水稻害虫（如瘿蚊 `Gallmidge`、褐飞虱 `Brownplanthopper` 等）为代表的生物灾害时间序列具有显著的“高度偏态（Highly Skewed)”特征：

1. **非爆发期极度稀疏**：绝大多数时间节点害虫数量接近于 $0$，处于漫长的平静期。
2. **爆发期突发性高且极端值密集**：一旦温湿度等气象条件达到阈值，虫口密度呈指数级暴增。

传统的单一回归模型（如普通 LSTM、SVR 等）在面对此类数据时，往往会陷入两难境地：要么为了迎合大量低值样本而“消极怠工”（不敢预测高洪峰，导致严重漏报），要么在平静期产生剧烈的微小波动（频繁乱报峰值，导致“狼来了”式的虚报）。

为此，本项目第一阶段摒弃了传统的单回归预测，创新性地提出了**多任务学习（Multi-Task Learning, MTL）与两阶段决策硬门控（Hard Gating Mechanism）相结合的专业预警方案**。

## 📊 二、 数据集与特征工程

本项目第一阶段选用长周期水稻病虫害与气象监测数据集（`RICE.csv`），涵盖了多种主要水稻病虫害及核心气象观测指标。

### 1. 研究对象（目标病虫害）

本阶段在以下 $6$ 类典型水稻病虫害上进行了广泛的建模与验证：

- **Gallmidge**（稻瘿蚊 —— 核心基准测试对象）
- **Brownplanthopper**（褐飞虱）
- **Greenleafhopper**（黑尾叶蝉）
- **LeafBlast**（稻瘟病/叶瘟）
- **LeafFolder**（稻纵卷叶螟）
- **Yellowstemborer**（三化螟）

### 2. 特征体系构建

| 特征类别              | 字段名称                | 物理含义与处理方式                                                                                |
| :---------------- | :------------------ | :--------------------------------------------------------------------------------------- |
| **目标变量 (Target)** | `Pest Value`        | 原始虫口密度/发病率，经 $\ln(1 + x)$ (`np.log1p`) 对数平滑处理以压缩极值跨度                                     |
| **衍生爆发标签**        | `Is_Outbreak`       | 依据对数变换后 `Pest Value` 的 $80\%$ 分位数（`quantile(0.8)`）动态定义前 $20\%$ 为爆发态（$1.0$），其余为平静期（$0.0$） |
| **基础气象特征**        | `MaxT` / `MinT`     | 当周最高气温 / 最低气温（$^\circ\text{C}$）                                                          |
| **基础气象特征**        | `RH1(%)` / `RH2(%)` | 晨间相对湿度 / 午间相对湿度（$\%$）                                                                    |
| **基础气象特征**        | `RF(mm)`            | 当周降雨量（$\text{mm}$）                                                                       |
| **基础气象特征**        | `WS(kmph)`          | 平均风速（$\text{km/h}$）                                                                      |
| **滑动窗口特征 (新增)**   | `Rain_Sum_4wk`      | 过去 $4$ 周累积降雨量：$\sum_{i=0}^{3} \text{RF}_{t-i}$，捕捉连阴雨等水分累积效应                              |
| **滑动窗口特征 (新增)**   | `Temp_Mean_4wk`     | 过去 $4$ 周平均最高温：$\frac{1}{4}\sum_{i=0}^{3} \text{MaxT}_{t-i}$，捕捉积温孵化效应                     |

> **数据标准化**：所有输入特征均通过 `StandardScaler` 进行零均值单位方差标准化（$z = \frac{x - \mu}{\sigma}$），并按 $8:2$ 划分训练集与测试集。

## 🧠 三、 核心建模方法论

### 1. 数据与特征层：捕捉生物累积效应与短期诱因

传统的模型只看当前节点的天气，容易忽略生物学上的滞后性。我们在数据源头进行了两次关键改造：

- **滚动窗口特征（Rolling Features）**：引入了过去 $4$ 周的“累积降雨量（`Rain_Sum_4wk`）”与“平均最高温（`Temp_Mean_4wk`）”。害虫虫卵孵化与爆发往往依赖于持续的温湿度温床，滚动特征能让模型显式捕捉这种环境生物累积效应。
- **时序跨度优化（$\text{SEQ\_LEN} = 4$）**：将时间步长设定为 $4$，配合 $4$ 周滑动特征，使模型既具备过去一个月的宏观气候背景感知，又能对近 $4$ 周内的短期气象剧烈波动（爆发诱因）保持极高的敏感度。

### 2. 模型架构层：共享骨干网络与多任务双头

模型（`EnhancedModel`）采用混合 **CNN-LSTM** 架构作为特征提取的共享骨干网络（Shared Backbone），并在末端分化出两个独立的输出头（Dual Heads）：

```text
输入序列 X (Batch, Seq_Len=4, Features=9)
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│ 共享骨干网络 (Shared Backbone: CNN-LSTM)                │
│  ├─ 1D-CNN: Conv1d(9 -> 128, k=3, p=1) + BN + ReLU      │  <-- 捕捉多维气象特征短期局部时空关联
│  ├─ Dropout(0.2)                                        │
│  └─ 2-Layer LSTM: Hidden_Size=256, Dropout=0.3          │  <-- 提取长短期时序依赖，取末步隐状态 h_T
└─────────────────────────────────────────────────────────┘
       │
       ├─────────────────────────────┬─────────────────────────────┐
       ▼                             ▼                             ▼
┌───────────────────────────┐ ┌───────────────────────────┐ ┌───────────────────────────┐
│   回归头 (Regressor)      │ │   分类头 (Classifier)     │ │ 推理期硬门控 (Hard Gate)  │
│ Linear(256->64) + ReLU    │ │ Linear(256->64) + ReLU    │ │ 若 P(Outbreak) < 0.5:     │
│ Linear(64->1)             │ │ Linear(64->1) + Sigmoid   │ │ 强制截断回归输出为 -0.8   │
│ 输出: 对数空间虫量预测值   │ │ 输出: 爆发态概率 (0 ~ 1)   │ │ 反变换后彻底熨平低值噪点   │
└───────────────────────────┘ └───────────────────────────┘ └───────────────────────────┘
```

- **CNN 层**：利用一维卷积（`Conv1d`）在特征维度上滑动，捕捉温、湿、雨、风各气象特征在短期内的局部耦合关联。
- **LSTM 层**：通过双层长短期记忆网络提取序列内部的时间依赖关系，输出高阶时序特征向量。
- **分类头 (Classifier Head)**：通过 $\text{Sigmoid}$ 激活函数，预测当前是否处于“爆发态”（概率 $0 \sim 1$）。强行让模型学会区分“平静期”与“爆发期”的特征边界。
- **回归头 (Regressor Head)**：负责线性输出，预测对数变换后的害虫具体数值。

### 3. 损失函数层：动态梯度平衡与鲁棒优化

多任务模型的核心在于如何协同训练。代码通过定制化的联合损失函数（Joint Loss）对反向传播梯度进行精细调控：

$\text{Total Loss} = \text{Loss}_{\text{reg}} + \lambda \times \text{Loss}_{\text{cls}} \quad (\lambda = 3.0)$

- **分类优化 (Focal Loss)**：非爆发样本远多于爆发样本（非平衡数据）。传统的交叉熵（BCE）会让模型倾向于全猜负类。引入 Focal Loss（$\alpha = 0.25, \gamma = 2$），迫使模型将注意力集中在那些“极难被分类的爆发拐点”上：
  $\text{FL}(p_t) = -\alpha (1 - p_t)^\gamma \log(p_t)$
- **回归鲁棒化 (Huber Loss)**：传统的均方误差（MSE）在爆发期预测偏差较大时会产生平方级惩罚爆炸，导致模型畏手畏脚不敢预测高值。Huber Loss（$\delta = 1.0$）在大误差时转化为线性惩罚，降低了离群极值对整体权重的破坏，使模型更敢于尝试拟合高数值洪峰。
- **梯度平衡（权重系数** **$\lambda = 3.0$）**：给分类损失赋予更高的权重进行梯度放大，向网络传递强信号——**“宁可数值存在一定偏差，绝不可漏报爆发态”**，以此引导骨干网络优先提炼与灾害危机相关的特征。

### 4. 决策推断层：硬门控机制消除“伪爆发”

在最终的预测推理阶段（Inference），模型实施了两阶段硬门控（Hard Gating）决策逻辑，有效解决了传统模型在低值期频繁波动、乱报峰值的通病：

1. **第一阶段（资质审查）**：首先查看分类头的输出概率 $P_{\text{cls}}$。若分类器认为当前气象条件触发爆发的概率 $P_{\text{cls}} < 0.5$（可调阈值），说明当前不具备爆发温床。
2. **第二阶段（硬性截断）**：一旦触发上述条件，门控机制直接剥夺回归头的预测权，强制将该节点的标准化回归预测值重置为低值常数（$-0.8$），再经逆标准化与 $\exp(x) - 1$（`np.expm1`）反变换及非负截断（$\max(\hat{y}, 0)$），从而完美熨平平静期的“预测噪点”。

### 2. 农业场景下的核心指标深度解读

以核心测试对象 **稻瘿蚊 (Gallmidge，实验组 3)** 的指标为例，我们将机器学习指标映射至真实农业防灾场景中进行解读：

1. **预警精确率 ($\text{Precision} = 67.92\% \sim 81.25\%$)**
   - **统计含义**：在模型所有拉响爆发警报的次数里，真正发生虫害大爆发的概率约为 $68\% \sim 81\%$。
   - **农业映射**：这意味着模型的“虚报率”控制在 $19\% \sim 32\%$ 左右。在农业防灾减灾任务中，这一虚报率处于非常低且完全可接受的区间。农户或植保人员根据系统警报下田巡查，每 $3 \sim 4$ 次中有 $2 \sim 3$ 次能精准抓到正在爆发的害虫，不会因为频繁的“狼来了”而产生抗拒心理与防治疲劳。
2. **预警召回率 ($\text{Recall} = 66.67\% \sim 68.00\%$)**
   - **统计含义**：在大自然所有真正发生过的大爆发中，模型成功提前捕捉到了约 $2/3$。
   - **农业映射**：模型成功拦截了绝大多数重特大灾害，但仍有约 $1/3$ 的灾害成为“漏网之鱼”（漏报率约 $33\%$）。漏报在农业生产中潜在风险较高，因此进一步提升 $\text{Recall}$（例如动态下调门控阈值或调整 Focal Loss 的 $\alpha$ 因子）是我们下一阶段的攻关方向。
3. **$\text{KGE Efficiency}$** **($0.2465 \sim 0.4843$) 与** **$R^2$** **($0.2430 \sim 0.4360$)**
   - **统计含义**：Kling-Gupta 效率系数（$\text{KGE}$）综合考量了相关性、偏差和变异度，与 $R^2$ 共同反映回归部分的数值拟合优度。
   - **农业映射**：两项指标客观表明模型能够有效跟上虫害波动的**洪峰趋势**（得益于分类头的强力带动以及硬门控对平静期噪点的抹除），但在极端特大洪峰的绝对高度拟合上，仍有进一步优化的空间。
